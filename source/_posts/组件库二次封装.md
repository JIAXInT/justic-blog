# 组件库二次封装完整指南

## 概述

在实际开发中，我们经常需要对第三方组件库（如 Element Plus、Ant Design Vue 等）进行二次封装，以满足业务需求、统一 UI 风格或简化使用方式。本文将详细介绍 Vue3 中组件二次封装的核心技术点和最佳实践。

## 二次封装要考虑的问题

1. **Props 如何穿透** - 确保原组件的所有属性都能正确传递
2. **插槽如何穿透** - 保持原组件的插槽功能
3. **组件的方法如何暴露** - 让父组件能够调用子组件的方法
4. **事件如何传递** - 确保事件能正确向上冒泡
5. **类型安全** - 保持 TypeScript 的类型提示

## 属性的穿透

### 问题分析

当我们直接使用 `v-bind="$attrs"` 时，虽然能传递所有属性，但会丢失 TypeScript 的类型提示：

```html
<!-- 简单绑定，但会丢失TypeScript类型提示 -->
<el-input v-bind="$attrs"></el-input>
```

### 解决方案

我们需要声明 props 并设定相应的类型，但这样会导致所有属性变成必传的。使用 `Partial` 工具类型可以解决这个问题：

```html
<template>
  <div>
    <!-- 合并$attrs和props，确保所有属性和事件都能正确传递 -->
    <el-input v-bind="{...$attrs,...props}"></el-input>
  </div>
</template>

<script lang="ts" setup>
  import { type InputProps } from "element-plus";

  // 使用Partial让所有InputProps的属性变成可选的，避免必传问题
  const props = defineProps<Partial<InputProps>>();
</script>
```

### Partial 工具类型详解

`Partial<T>` 是 TypeScript 提供的工具类型，它将类型 T 的所有属性都变成可选的：

```typescript
// 原始类型
interface InputProps {
  placeholder: string;
  disabled: boolean;
  size: "large" | "default" | "small";
}

// 使用Partial后
type OptionalInputProps = Partial<InputProps>;
// 等价于：
// {
//   placeholder?: string;
//   disabled?: boolean;
//   size?: 'large' | 'default' | 'small';
// }
```

## 插槽的穿透

### 使用 h 函数实现插槽穿透

`h` 函数是 Vue3 中用于创建虚拟 DOM 节点的渲染函数，它是 `createElement` 的简写形式。

#### h 函数语法

```typescript
h(type, props?, children?)
```

- **type**: 组件类型（HTML 标签名、组件对象或异步组件）
- **props**: 属性对象（可选）
- **children**: 子节点或插槽对象（可选）

#### 实现插槽穿透

```html
<template>
  <div>
    <!-- 使用h函数创建组件，第三个参数$slots传递所有插槽 -->
    <component :is="h(ElInput,{...$attrs,...props},$slots)"></component>
  </div>
</template>

<script lang="ts" setup>
  import { h } from "vue"; // 导入h函数用于创建虚拟节点
  import { ElInput, type InputProps } from "element-plus";

  const props = defineProps<Partial<InputProps>>();
</script>
```

#### h 函数的高级用法

```typescript
// 传递具名插槽
h(
  ElInput,
  {
    placeholder: "请输入",
  },
  {
    prefix: () => h("span", "前缀"),
    suffix: () => h("span", "后缀"),
    default: () => h("span", "默认内容"),
  }
);

// 传递作用域插槽
h(
  ElInput,
  {
    placeholder: "请输入",
  },
  {
    default: (props) => h("span", `作用域插槽: ${props.value}`),
  }
);
```

## 方法的穿透

### 获取组件实例

我们需要通过 `ref` 回调函数获取子组件实例，然后使用 `getCurrentInstance` 将其暴露给父组件：

```html
<template>
  <div>
    <!-- 通过ref函数获取子组件实例 -->
    <component
      :is="h(ElInput,{...$attrs,...props,ref:changeRef},$slots)"
    ></component>
  </div>
</template>

<script lang="ts" setup>
  import { h, getCurrentInstance } from "vue";
  import { ElInput, type InputProps } from "element-plus";

  const props = defineProps<Partial<InputProps>>();

  // 获取当前组件实例
  const vm = getCurrentInstance();

  // ref回调函数，用于获取子组件实例并暴露给父组件
  function changeRef(inputInstance) {
    // 将子组件实例暴露给父组件，等同于defineExpose
    vm.exposed = inputInstance || {};
    vm.exposeProxy = inputInstance || {};
  }
</script>
```

### 使用 vm.exposed 的方案

我们可以使用 `getCurrentInstance` 获取组件实例，然后通过 `vm.exposed` 暴露方法：

```html
<script lang="ts" setup>
  import { h, getCurrentInstance } from "vue";
  import { ElInput, type InputProps } from "element-plus";

  const props = defineProps<Partial<InputProps>>();

  // 获取当前组件实例
  const vm = getCurrentInstance();

  // ref回调函数，用于获取子组件实例并暴露给父组件
  function changeRef(inputInstance) {
    // 将子组件实例暴露给父组件，等同于defineExpose
    vm.exposed = inputInstance || {};
    vm.exposeProxy = inputInstance || {};
  }
</script>
```

## 完整示例

### 封装后的 Input 组件

```html
<template>
  <div class="custom-input-wrapper">
    <component
      :is="
        h(
          ElInput,
          {
            ...$attrs,
            ...props,
            ref: changeRef,
            class: 'custom-input',
          },
          $slots
        )
      "
    />
  </div>
</template>

<script lang="ts" setup>
  import { h, getCurrentInstance } from "vue";
  import { ElInput, type InputProps } from "element-plus";

  // 定义props，使用Partial让所有属性可选
  const props = defineProps<Partial<InputProps>>();

  // 获取当前组件实例
  const vm = getCurrentInstance();

  // ref回调函数，用于获取子组件实例并暴露给父组件
  function changeRef(inputInstance) {
    // 将子组件实例暴露给父组件，等同于defineExpose
    vm.exposed = inputInstance || {};
    vm.exposeProxy = inputInstance || {};
  }
</script>

<style scoped>
  .custom-input-wrapper {
    position: relative;
  }

  .custom-input {
    /* 自定义样式 */
  }
</style>
```

### 使用示例

```html
<template>
  <div>
    <!-- 基本使用 -->
    <CustomInput
      v-model="value"
      placeholder="请输入内容"
      @input="handleInput"
    />

    <!-- 使用插槽 -->
    <CustomInput v-model="value">
      <template #prefix>
        <span>🔍</span>
      </template>
    </CustomInput>

    <!-- 调用方法 -->
    <button @click="focusInput">聚焦输入框</button>
  </div>
</template>

<script setup>
  import { ref } from "vue";
  import CustomInput from "./CustomInput.vue";

  const value = ref("");
  const inputRef = ref();

  const handleInput = (val) => {
    console.log("输入值:", val);
  };

  const focusInput = () => {
    inputRef.value?.focus();
  };
</script>
```

## 总结

组件库二次封装是 Vue3 开发中的重要技能，通过合理使用 `h` 函数、`Partial` 类型和 `vm.exposed`，我们可以创建既保持原组件功能又满足业务需求的封装组件。关键是要理解 Vue3 的响应式系统、组件通信机制和 TypeScript 的类型系统。

### 核心技术要点回顾：

1. **属性穿透**：使用 `v-bind="{...$attrs, ...props}"` 合并属性和 props，配合 `Partial<T>` 类型让属性可选
2. **插槽穿透**：使用 `h` 函数的第三个参数传递 `$slots`，实现插槽的完整传递
3. **方法暴露**：通过 `getCurrentInstance()` 获取组件实例，使用 `vm.exposed` 和 `vm.exposeProxy` 暴露子组件方法
4. **类型安全**：使用 TypeScript 的 `Partial` 工具类型确保类型提示和可选属性

### 技术方案对比：

| 技术点   | 传统方案          | 推荐方案                         |
| -------- | ----------------- | -------------------------------- |
| 属性传递 | `v-bind="$attrs"` | `v-bind="{...$attrs, ...props}"` |
| 类型定义 | 直接使用原类型    | `Partial<ComponentProps>`        |
| 插槽传递 | 手动定义插槽      | `h(Component, props, $slots)`    |
| 方法暴露 | `defineExpose`    | `vm.exposed = instance`          |

这种封装方式既保持了原组件的所有功能，又提供了良好的类型支持和开发体验。
